# Trabajo en Afinia

Este repositorio contiene Afinia. Lee `README.md` y las últimas entradas de
`docs/STATUS.md` para conocer el alcance actual antes de intervenir.

## Diseño y experiencia de usuario

Para diseñar, construir, revisar o modificar pantallas y componentes de la
interfaz, utiliza la skill local `frontend-design`:

1. Lee `.agents/skills/frontend-design/SKILL.md`.
2. Lee `.agents/skills/frontend-design/references/afinia.md` como brief del
   producto y contexto de las decisiones aprobadas.
3. Aplica el proceso de diseño, implementación y revisión visual a la tarea
   autorizada, con una profundidad proporcional al cambio.

Las instrucciones y decisiones del usuario tienen prioridad. Las referencias
generales de la skill se interpretan en el contexto de Afinia; las revisiones
internas no añaden una aprobación extra a cambios ya autorizados. Consulta
información faltante solo cuando sea necesaria para resolver una ambigüedad real.

El alcance de instalación de esta skill es este repositorio. Su procedencia y
licencia están documentadas en
`.agents/skills/frontend-design/UPSTREAM.md`.

## Entrega

Verifica los recorridos afectados y la adaptación móvil según el cambio. Los
cambios solo de documentación o instalación de skills se verifican leyendo sus
archivos y referencias; no requieren ejecutar pruebas de la aplicación.

Al terminar cada implementación, explica brevemente qué cambió, cómo se comprobó
y qué viene después. Distingue la maqueta local de las funciones reales del piloto.
