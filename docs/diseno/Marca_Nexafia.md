# Marca Nexafia y revisión del recorrido

El usuario eligió Nexafia y autorizó aplicar el cambio y revisar el recorrido móvil.
Se actualizan logotipo tipográfico, cabeceras, título/descripción HTML, etiquetas
accesibles, cuenta, avisos de imágenes, mensajes SMTP y descargas. No se rediseña
el símbolo floral ni se añaden servicios. La alternativa de renombrar claves,
cookies y base de datos introduciría migraciones innecesarias: se mantienen las
referencias técnicas heredadas y los documentos históricos.

Dirección visual: verde #285d4c, tinta #293e35, fondo #faf9f6, crema #f3f1e8 y línea
#e7e8df; Inter para interfaz y Georgia para marca/títulos. Misma composición y
alineación de los tres espacios; revisar que la palabra más larga quepa en la
barra lateral, cabecera móvil y pie. Principio: reconocer el nuevo nombre sin
interrumpir publicaciones, imágenes, favoritos, bloqueos o reservas existentes.

Comprobación: compilar demo y piloto; revisar Plaza → publicar/responder →
invitación contextual → Conexiones → Encuentros, además de cuenta y descargas.
Revisión renderizada a 320, 390 y 1440 px, foco, diálogos y ausencia de
referencias de marca antiguas visibles. La pauta de prueba con cinco personas
es un documento de facilitación; no se recluta ni contacta a nadie.
