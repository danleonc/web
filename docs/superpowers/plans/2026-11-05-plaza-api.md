# API de La Plaza, etapa interna

**Objetivo:** conectar la persistencia de Plaza a una API verificable entre cuentas, sin habilitarla en producción antes de completar moderación y producto. Especificación: `../../../../BETA_NEXAFIA_PROPUESTA.md`.

**Arquitectura:** integrar un manejador HTTP al servidor existente, habilitado únicamente mediante opción interna de pruebas. Aplicar sesión y correo confirmado existentes, comprobación de origen para cambios, límites de tamaño y propiedad en servidor. No confiar en identificadores de autor del cliente.

- [x] Escribir pruebas HTTP reales con dos cuentas, cuenta sin confirmar, origen incorrecto, persistencia tras reinicio, edición/borrado ajenos y API desactivada por defecto; confirmar fallo.
- [x] Implementar rutas de publicaciones y respuestas con validación y límites; mantenerlas desactivadas por defecto.
- [x] Probar regresión de servidor y compilación, y documentar que faltan interfaz, moderación y límites operativos antes de apertura.

Resultado: 57 pruebas de servidor y compilación piloto correctas. Revisión propia: la lectura requiere una cuenta confirmada y devuelve como máximo 100 elementos; faltan exploración pública, paginación real, cuotas antispam, reportes y moderación de Plaza antes de activar la API. No existe un interruptor de producción que la habilite.
