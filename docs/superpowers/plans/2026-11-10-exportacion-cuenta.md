# Exportación de contenido propio de cuenta

Primera descarga de datos propios en JSON para el servidor interno. La sesión autenticada solo obtiene sus propios datos; se excluyen credenciales, mensajes de otras personas, evidencias administrativas y archivos binarios. No se presenta esta descarga como cumplimiento legal ni exportación integral de datos personales. Cada página contiene hasta 1.000 registros por sección e indica si hay más. Las páginas se consultan por separado y no forman una instantánea: cambios concurrentes pueden mover registros entre páginas. Una eliminación responsable y una exportación completa requieren políticas, derechos de terceros y revisión jurídica pendientes.
