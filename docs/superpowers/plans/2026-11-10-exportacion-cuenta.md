# Exportación de contenido propio de cuenta

Primera descarga de datos propios en JSON para el servidor interno. La sesión autenticada solo obtiene sus propios datos; se excluyen credenciales, mensajes de otras personas, evidencias administrativas y archivos binarios. No se presenta esta descarga como cumplimiento legal ni exportación integral de datos personales. Las tablas crecen sin límite: cada sección se acota y declara si está truncada. Una eliminación responsable y una exportación completa requieren políticas, derechos de terceros y revisión jurídica pendientes.
